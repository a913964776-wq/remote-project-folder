# 服务器项目文件夹 v1.0.0

用于 Windows 的远程项目文件入口，基于 WinSCP 6.7。无需安装 Python、Node.js 或单独安装 WinSCP。

## 首次使用

1. 将整个 ZIP 解压到长期保留的文件夹，例如 `D:\工具\服务器项目文件夹`。不要直接在压缩包中运行。
2. 双击 `服务器项目文件夹.exe`。
3. 填写服务器 IP、端口（通常为 22）、用户名、密码和项目根目录。目录必须填写服务器上的完整路径，例如 `/home/你的账号/项目目录`。
4. 点击“保存并打开”。程序会在桌面创建“服务器项目文件夹”和“服务器项目-修改配置”两个快捷方式。
5. 首次连接会显示服务器身份指纹，请向服务器管理员核对后接受。之后使用已缓存的身份信息连接；不会自动接受变化的服务器身份。

以后双击桌面“服务器项目文件夹”，直接连接配置的项目目录。软件所在文件夹不要删除或移动；移动后打开新位置的“修改连接配置.cmd”，保存配置即可重新生成快捷方式。

## 日常操作

- 左侧为服务器目录树，右侧为文件列表；打开目录查看内容。
- 双击文件，通过本地关联的软件打开。需要电脑上已有对应的查看软件。
- 将文件拖到桌面或本地文件夹，即下载副本；将本地文件拖到服务器窗口，即上传。这里的拖拽默认按复制处理。
- 同名覆盖与删除仍需要确认；本地副本不会持续自动同步。
- Claude 在服务器写入新文件后，按 `Ctrl+R` 刷新列表。
- 修改服务器、账号、端口或根目录：先关闭项目窗口，再打开桌面“服务器项目-修改配置”，或解压目录中的“修改连接配置.cmd”。

服务器目录直接来自 SFTP，不需要将整个项目预先同步到本地。打开文件和传输文件仍需要网络和下载时间。此版本使用临时文件方式拖出文件，不安装系统拖拽扩展；拖出大文件时会先下载到临时目录。

## 密码与同事分发

分发的 ZIP 没有预置服务器地址、账号、密码、密钥或个人连接记录。每位同事首次使用时填写自己的连接信息。

勾选记住密码后，持久化配置使用 Windows 当前用户的 DPAPI 加密；取消勾选后，密码应在连接窗口中输入。再次配置时密码留空，会保留同一服务器、端口和账号的已保存密码；更换服务器或账号不会沿用旧密码。

配置位于 `%LOCALAPPDATA%\RemoteProjectFolder`。连接运行期间，会在该位置生成 WinSCP 原生格式的会话文件；其中密码使用 WinSCP 原生可逆编码，正常退出时启动器会移除该密码字段。异常终止可能留下会话文件，因此不应分享此目录。加密不能防止同一 Windows 账号下运行的其他程序读取凭据。不要用复制个人配置目录的方式分发项目。

本版本每个 Windows 账号保存一个连接配置，且同一账号只运行一个本项目实例。高级认证（例如私钥或多因素认证）不在本配置界面中；当前面向密码登录的 SFTP 服务器。

## 环境和限制

- 目标环境：Windows 10/11，启用 .NET Framework 4.x；需具备访问服务器 SSH/SFTP 端口的网络权限。
- 不需要管理员权限，不改动系统已有 WinSCP 站点和界面配置。
- 文件浏览、上传和下载需要服务器账号具备对应权限。
- 双击文档后如在本地软件中保存，WinSCP 可能提示上传修改；单纯查看时直接关闭文件即可。
- 启动器为本项目编译的未签名程序；内置 WinSCP 保留原厂数字签名。

## 项目结构

```text
服务器项目文件夹.exe       可直接运行的启动器
修改连接配置.cmd           配置入口
src/Program.cs             完整启动器源码
build.ps1                  本地编译脚本
vendor/winscp/             原版 WinSCP、中文资源和许可
third-party-source/        WinSCP 6.7 对应版本源码存档
THIRD-PARTY.md             第三方来源说明
验证记录.md                本次实际验证及其边界
SHA256SUMS.txt             项目文件校验值
```

开发者重新编译：在项目目录使用 Windows PowerShell 执行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1`。脚本使用 Windows 自带 .NET Framework C# 编译器，不下载依赖。普通使用者无需编译。
