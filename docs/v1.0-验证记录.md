# v1.0.0 验证记录

验证日期：2026-10-31。

已完成：

- 使用本机 .NET Framework C# 编译器编译成功。
- 启动器自检通过：Windows DPAPI 加密/解密、无效主机配置拒绝、中文与百分号路径的 INI 编码、会话密码字段清理。
- 使用本项目生成的独立会话配置，通过内置 WinSCP 成功登录实际 Ubuntu 服务器，确认初始目录。
- 上传独立测试文件，再下载，SHA-256 一致，随后清理该远程测试文件。

- 交付包中不含个人 profile.xml、WinSCP.ini、密码文件、私钥或个人桌面快捷方式。

验证边界：

- 已验证的是当前 Windows 电脑与当前服务器；未在同事电脑上运行，未验证所有 Windows 版本和网络条件。
- 未完成配置界面逐项点击、桌面快捷方式生成和真实鼠标拖拽的自动化验收。这些行为使用 Windows Forms、WScript.Shell 和 WinSCP 原生功能实现。
- 上传下载的验证针对传输引擎，不代表已测试每种文件格式对应的本地查看软件。
- Windows 当前账号加密检查不代表独立安全审计。运行时会话文件的凭据处理边界见 README。

同事首次使用的建议验收：保存配置后关闭窗口，通过新建桌面快捷方式重连；将一个无敏感内容的测试文件拖入，再拖回桌面，确认可打开。
